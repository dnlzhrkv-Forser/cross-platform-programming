# ТСПП. Лабораторна робота №3: проєктування системи «ФармаОнлайн»

Каталог містить результати лабораторної роботи №3 з дисципліни «Технології створення програмних продуктів» для наскрізного проєкту «ФармаОнлайн» (застосунок для аптеки, варіант 7).

### Архітектурний стиль та архітектурна діаграма
Файл: `architecture-diagram.png`. Для системи обрано трирівневу (3-tier) клієнт-серверну архітектуру: веб-застосунок (SPA) звертається через Nginx до REST API на Node.js/Express, а доступ до даних PostgreSQL здійснюється лише з серверного рівня. Стиль обрано після порівняння з 2-tier та мікросервісами: він єдиний одночасно забезпечує безпеку (БД і ключі зовнішніх сервісів недоступні клієнту), масштабованість (stateless-сервер) і посильність для розроблення протягом семестру. Діаграма показує рівні системи, адаптери зовнішніх сервісів і напрямки взаємодії.

### ER-діаграма
Файл: `er-diagram.png`. Діаграму побудовано в Oracle SQL Developer Data Modeler; вона містить 19 сутностей (користувачі, препарати, аптеки, залишки, кошик, замовлення, е-рецепти, платежі тощо) і 25 зв'язків типів 1:1, 1:N та M:N через допоміжні таблиці. Модель приведено до третьої нормальної форми, а ціну позиції замовлення збережено окремо від каталогу, щоб фіксувати ціну на момент покупки.

### Каркас UX/UI (wireframe)
Файли: `wireframe-1-login-catalog.png`, `wireframe-2-drug-checkout.png`, `wireframe-3-queue-rx.png`. Каркаси шести екранів показують лише структуру без кольорів і графіки: вхід, пошук і каталог, картка препарату, оформлення замовлення, черга замовлень фармацевта та перевірка е-рецепта. Вони дозволили перевірити логіку навігації клієнта й фармацевта до початку візуального оформлення.

### Макет UX/UI (mockup)
Файли: `mockup-1-login-catalog.png`, `mockup-2-drug-checkout.png`, `mockup-3-queue-rx.png`. Макети тих самих шести екранів демонструють остаточний вигляд інтерфейсу: зелену палітру проєкту, шрифти, іконки та стилі елементів. Колір застосовано з урахуванням контрастності WCAG 2.1 AA, а позначку рецептурних препаратів виділено окремим кольором.
